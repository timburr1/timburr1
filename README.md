## Barkelona

[**Barkelona**](https://barkelona.com) is a comprehensible-input video game for Spanish learners that my wife and I made. The web version is free for classroom use, needs no student accounts, and stores no user data. [Barkelona.com](https://barkelona.com/Resources/) also has quizzes and resources for educators. It's available on [Steam](https://store.steampowered.com/app/2434300) and [Itch.io](https://hoodmentality.itch.io/barkelona).

## Lockscreen Maker

[Lockscreen Maker](https://purple-desert-013eefc10.5.azurestaticapps.net) is a static web site that composites user-supplied text (name, contact info, and similar) onto a background image sized for a chosen screen, and produces a single downloadable image so the result can be long-press saved and set as a phone lockscreen.

## TTRPG Generator

[TTRPG Generator](https://wonderful-meadow-038c5bc10.5.azurestaticapps.net/) is a static web page of generators for tabletop game masters, switched by tab links. The NPC generator makes a race-appropriate first name, last name, and a quirk, for a race and gender the DM picks or leaves random. The Tavern generator makes a name, an innkeeper, the mood of the room, and an odd building feature. The Side Effect generator rolls one to five distinct side effects, chosen by a slider. It deploys to the Azure Static Web Apps free tier; there is no backend.
